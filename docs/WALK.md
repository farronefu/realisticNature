# 森の中を歩く

## 起動

Windowsのエクスプローラーで `Start_Walk.cmd` をダブルクリックします。Blenderが開いたら、3D画面のヘッダーにある **「森を歩く」** をクリックしてください。起動直後は素材の読み込みとシェーダーの準備に時間がかかる場合があります。

F3で「森を歩く」を検索して実行することもできます。歩行モードに入ると、マウスで視線を動かせます。

| 操作 | キー |
|---|---|
| 前後・左右へ移動 | W / S / A / D、または矢印キー |
| 見回す | マウス |
| 速く移動 | Shiftを押しながら移動 |
| ゆっくり移動 | Altを押しながら移動 |
| 速度調整 | マウスホイール |
| 歩行を終了して現在の位置を保持 | 左クリック |
| 今回の歩行を取り消す | Esc、または右クリック |
| 地面に沿う歩行／自由移動を切り替え | Tab |
| ジャンプ（重力ON時） | V |
| 上下移動（重力OFF時） | E / Q |

歩行を終了した後、ヘッダーの家のアイコンを押すと、小道の入口へ戻れます。

## 表示と制作範囲

歩行時はEEVEEのリアルタイム表示を使います。保存済みのCycles静止画とは光や影の見え方が異なります。まずは入口から前方約30mの小道を歩いて確認してください。カメラ外のエリアは静止画用に簡略化されています。

Blenderの標準ナビゲーションを使うため、ゲームのキャラクターのような壁との衝突処理はありません。重力ONでは足元の表面を検出します。植生の上に乗った場合などはTabで自由移動へ切り替えられます。

## ファイルと設定

- `ForestPath_Walk_Packed.blend`：ローカル納品の歩行用ファイル。画像59点を内蔵。
- `tools/walk_mode.py`：目線・歩行速度・重力・表示・開始ボタンを設定。
- `tools/prepare_walk.py`：歩行用ファイルの生成と再読込検証。
- `docs/walk_validation.json`：検証結果。実際のキー入力による操作テストは含みません。

起動ファイルは、歩行用の素材内蔵版、静止画用の素材内蔵版、リポジトリの `scenes/ForestPath.blend` の順にファイルを探します。Git cloneした環境では先にREADMEの手順で素材を復元してください。

撮影用の `.blend` は書き換えません。表示やナビゲーションの設定は起動したBlenderの中で適用し、ユーザー設定の自動保存は行いません。スクリプトは起動ファイルから明示的に実行し、Blenderの「Pythonスクリプトの自動実行」を有効にする必要はありません。

歩行用 `.blend` を直接開く場合は、3D画面でF3 → `Walk Navigation`（ウォークナビゲーション）を実行できます。ただし、その開き方では開始ボタンや速度・重力の設定は適用されないため、`Start_Walk.cmd` からの起動を推奨します。

操作はインストール済みBlender 5.2.1の `scripts/presets/keyconfig/keymap_data/blender_default.py` にある `km_view3d_walk_modal` で確認しています。参考：[Blender公式マニュアル：Fly/Walk Navigation](https://docs.blender.org/manual/sl/4.5/editors/3dview/navigate/walk_fly.html)。
