# 森の小道：フォトリアル表現の調査と制作判断

調査日：2026-09-09。添付写真は構図・密度・質感の参考として使用。画素のコピー、写真の投影、画像生成による完成画像の代用は行っていない。

## 実装した方法

| 課題 | 採用した方法 | 確認する点 |
|---|---|---|
| 森の実寸 | メートル単位、スキャンの寸法を維持した樹木・岩・根 | 巨大な葉、不自然に細い幹を避ける |
| 人が通る道 | 曲線の中心線、左右の異なる土手高さ、道幅の変化 | 中央の歩行帯が植生で完全に塞がれない |
| 地形の人工的な滑らかさ | 大・中・小の凹凸、スキャン変位、独立した小石 | 同じ大きさのノイズだけで地形を作らない |
| 斜面での画像の伸び | ワールド座標のボックス投影、高さマップのバンプ | 急な土手にトップダウンUVの縦筋が出るのを修正 |
| 岩の接地 | 大岩を土手に埋める、小岩・根・シダで接点をつなぐ | 浮いた岩、一直線の石垣を修正 |
| 植生の反復 | シダ4種、樹木3種、低木4種を共有メッシュで配置 | 回転・スケール・密度を変え、道を除外 |
| 苔の質感 | Megascans 4K苔、上向き面とノイズの混合、実体の苔の葉 | 一様な緑の塗装を避ける |
| 地面との融合 | MegascansのOpacityと四辺フェードで地形沿いのデカール | 四角い境界、深度競合を確認 |
| 地表の細部 | 立体の巻いた落ち葉、枝、道を横切る先細りの根 | 接触影とシルエットをテクスチャだけに任せない |
| 森の環境光 | Poly Haven Forest Slope 4K HDRI | 木陰にも周囲の光が残ること |
| 遠景の縮尺 | 実体の木々と地面を延長、遠景のみ薄い空気散乱 | HDRIの近い幹が巨大な遠景として映るのを避ける |
| 木漏れ日 | 小さい角度のSunと実際の樹冠の遮蔽 | 不自然な均一スポットライトを置かない |
| 葉の質感 | 元の透過・裏面表現、少量のSSS、対応ノードではDiffuse Transmission | 葉が黒い板や発光するプラスチックに見えない |
| カメラ | フルサイズ相当32mm、低めの視点、f/8、10mに合焦 | 風景写真として自然な奥行き、過度なボケを避ける |
| 階調 | AgX、ハイライトのロールオフ、控えめな露出補正 | 日向の白飛びと日陰の黒つぶれを見比べる |
| レンダリング | Cycles、OptiX、適応サンプリング、OIDN | 葉の細部、暗部、透明の重なりのノイズを確認 |
| データの解釈 | 色はsRGB、法線・粗さ・変位・OpacityはNon-Color | DirectX法線はYを反転してBlenderへ接続 |

## 比較して採用しなかったもの

- 強い霧・ゴッドレイ：湿った森を霧で隠す方向に寄りすぎるため不採用。追加修正では遠景に限定した低密度0.0025の空気散乱を使用。
- 強い被写界深度、色収差、周辺減光：ディテールの不足を隠す効果として使わない。
- 全アセット8K化：カメラ距離とGPUメモリに対して効果が低いものは2K～4Kを採用。
- すべて実体複製：同じメッシュを共有し、レンダリング時のインスタンスとして利用。
- 高密度な一様散布：植生の群生、道の踏まれる部分、根元の遮蔽を優先。
- FabのNordic Forest Cluster Rock SmallおよびGranite Rock：ページでは無料～有料のライセンス選択があり、Blender用ソース形式を無料で取得できることを確認できなかったため、岩本体はCC0スキャンを使用。

## 一次資料

- [Blender Cycles Sampling](https://docs.blender.org/manual/en/3.6/render/cycles/render_settings/sampling.html)：適応サンプリングとデノイズの基本。実装値はインストール済み5.2.1のAPIで確認。
- [Blender Light Paths](https://docs.blender.org/manual/en/dev/render/cycles/render_settings/light_paths.html)：透明のバウンスは通常のバウンスと別に設定。樹冠の重なりを考慮して24。
- [Blender Color Management](https://docs.blender.org/manual/en/4.3/render/color_management.html)：AgXとデータテクスチャの色空間。
- [Poly Haven HDRI guide](https://docs.polyhaven.com/en/guides/hdris)：パストレーサーにおけるHDRI利用。
- [Forest Slope](https://polyhaven.com/a/forest_slope)：森林斜面の実測HDRI。照明に使用。カメラから直接見える背景は3D樹木と空へ変更。
- [Fab Standard License](https://www.fab.com/eula)：Blenderで使用可能。素材本体の単体再配布には制限があるため、公開GitリポジトリにMegascansのマップは同梱しない。
- [Poly Haven License](https://polyhaven.com/license)：採用した補助モデル・HDRI・テクスチャはCC0。

設定は写真らしさの保証ではなく、実写に近づける制作上の判断。最終の解像度・実測時間・依存ファイルチェックは `validation.json` を参照。
